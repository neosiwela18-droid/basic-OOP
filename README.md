# Book Borrowing System

a simple Python program using object-oriented programming.

I created a `Book` class that stores:

- The book title
- The author
- The borrowing status
- A history list for future borrowing records

I added a `borrow()` method that allows a book to be borrowed only when it is available. I also added a `return_book()` method that changes the book's status back to available.

The `__str__()` method displays each book's title, author, and current status.

I tested the program using two books: *Wealth of Nations* by Adam Smith and *The Forms* by Plato. This project helped me practise classes, objects, attributes, methods, conditional statements, and object state management.
